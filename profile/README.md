# Can you trace a report’s claims back to its data?

A report gives you a number. Before you publish it, cite it or act on it, you may want to know whether the original measurements support it. **FLORN checks claims in a report against the data supplied with it.** For each claim it can assess, you can see the verdict and the source behind it.

## A published result you can check yourself

In a 2024 *Nature Communications* paper, Broz and colleagues reported the average number of a particular type of cell in two groups. Each average in Figure 3a came from five measurements. Do the published numbers agree with the authors’ workbook?

| Group | Mean from the source data | Reported in the paper |
| --- | ---: | ---: |
| Ccne1+ | 45,026.72 | 45,027 |
| Vgll3+ | 68,194.48 | 68,194 |

Both means match at the precision used in the paper. The result covers those two numbers. The statistical comparison and the biological conclusions are separate questions. [Open the case, source workbook and verdicts](https://florn.ai/results/sarcoma-figure-3a)

## Reading a FLORN result

- **Supported.** The supplied data reproduce the claim at the stated precision.
- **Contradicted.** The source yields a result that conflicts with the claim.
- **Unresolved.** The available evidence is insufficient to decide. The result identifies what is missing.

If you are reviewing a manuscript or checking a report produced by an AI assistant, start with a figure or table whose source data you have.
